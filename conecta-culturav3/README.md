# Conecta Cultura v2
Plataforma web educativa y cultural enfocada en la difusión de actividades artísticas y talleres comunitarios.

## Estructura del Proyecto
- `index.html`: Página principal con videos y mapas integrados.
- `nosotros.html`: Información sobre la misión y visión institucional.
- `noticias.html`: Cartelera general de novedades de la organización.
- `noticia-detalle-1.html`: Reportaje sobre Fotografía Urbana.
- `noticia-detalle-2.html`: Reportaje sobre Huertos Comunitarios.
- `contacto.html`: Nueva sección con la tabla de talleres y formulario avanzado de inscripción.
- `assets/css/estilos.css`: Hoja de estilos unificada compatible con Grid, Flexbox y Variables CSS.
- `assets/js/app.js`: Script lógico de control de navegación interactiva.
